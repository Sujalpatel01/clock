Jyotirlinga Clock - Sacred Time
Jyotirlinga Clock is a web application that displays the current time and date with a uniquely themed interface. Inspired by cultural heritage, the clock also features a modal with Jyotirlinga information, along with supported language and theme toggling options.

Features
Real-Time Clock: Displays both analog and digital time.
Dynamic Date Display: Shows the current date, weekday, month, and year.
Themed Interface: Multiple themes (default, gold, green) and language toggle (English & ગુજરાતી મોડ).
Jyotirlinga Modal: Provides additional information with images, audio, video, and shloka texts.
Background Music: (Optional) Autoplay background music on page load using muted auto-play with unmute.
Technologies
HTML5 for structure.
CSS3 for styling and animations.
JavaScript ES6 for dynamic data and event handling.


Usage
Theme & Language: Use the theme buttons and language toggle to switch between themes and languages.
Modal Info: Click on clock buttons to learn more about each Jyotirlinga.
Audio: The app attempts to autoplay background audio; if blocked, interact with the page to enable sound.
